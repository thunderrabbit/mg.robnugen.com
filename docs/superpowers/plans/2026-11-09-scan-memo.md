# Scan Memo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tools/site-standards/scan.sh` reuses a check's last pass/fail when the site's commit, the check, its inputs and its tools are all unchanged, so an unchanged rescan of `mg` takes about 5 s instead of 25 s.

**Architecture:** A new stdlib module `memo.py` builds a content key per (site, check) and keeps one JSON memo file per site under the XDG state directory. `scan.py` asks the memo before running a check that opted in with a `# memo: commit` header line, and records pass/fail afterwards. Checks without the header run every scan, exactly as today.

**Tech Stack:** Python 3 stdlib (`hashlib`, `json`, `unittest`), bash check scripts.

**Spec:** Agreed in chat on 2026-11-09 (no separate design document). The agreement is restated in Global Constraints and Task notes below. Baseline measured the same day for `mg`: 25 s, of which ~18 s is three docker-backed checks (`code_runs_on_php` 6.8 s, `phpstan_top` 5.4 s, rector 5.8 s; the second rector check reuses the first's run through `SCAN_TMP`), ~4.5 s is the other ~20 checks, ~1.7 s is the ssh that asks the deployed commit.

## Global Constraints

- Opt-in only: a check is memoized only if one of its first 20 lines is exactly `# memo: commit`. No header, no memo. A new or forgotten check is therefore never wrongly remembered.
- Key = site commit + bytes of the check script + bytes of `lib.sh` + bytes of every non-`.sh` file in `checks/` (helpers such as `js_scripts.py`) + the step `param` + all `SITE_*` facts the check receives + one tool identity (hash of `standards-mcp/run-*.sh` plus the IDs of local `standards-*` docker images).
- Store only outcomes `pass` and `fail`. Never `unknown`, never a timeout.
- Memo file: `${XDG_STATE_HOME:-$HOME/.local/state}/site-standards/memo-<shortcode>.json`, one per site, nothing in the repo, nothing sent to mg. Entries for commits other than the site's current one are dropped on save (my call).
- A remembered result prints on stderr as `(remembered from YYYY-MM-DD HH:MM TZ)` in local time with an absolute timestamp. The document sent to mg is identical to a fresh run's (my call, so mg's `states_unchanged` still counts correctly).
- `scan.sh --fresh` ignores memo reads, runs every check and rewrites the memo.
- The hand-rolled memos in `suite_passes_on_php.sh` and `js_deprecations_clear.sh` stay as they are; those checks do not opt in.
- `scan.py` runs under `python3 -I`, which leaves its own directory off `sys.path`; importing `memo` needs an explicit `sys.path.insert(0, HERE)`.
- `checks_match` must also cover `memo.py`, or a scan could run a memo layer that is not the deployed one.
- This repo is public: tests and comments use `mg` or made-up names, never real site shortcodes.
- Gates before reporting done: `~/work/rob/standards-mcp/run-unit.sh`, `run-phpcs.sh`, `run-phpstan.sh` on `~/work/rob/mg.robnugen.com`, plus `python3 -I -m unittest discover -s tools/site-standards/tests`.
- Commit rules from `~/.claude/CLAUDE.md`: multiple `-m` flags (never a heredoc), subject ≤50 chars, imperative, body says why, end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Claude cannot commit on master.

## Review Focus

- A memo file that is truncated, hand-edited or not JSON: treated as empty, the scan carries on and rewrites it.
- State directory unwritable or `HOME` unset: the scan still runs unmemoized and says so in one stderr line.
- A check that exits 2 or times out: never stored, so the next scan runs it again.
- A fact change (for example `SITE_PHP_CURRENT` 8.4 → 8.5) or a changed `param`: the key misses and the check reruns.
- An opted-in check that reaches outside the repo (ssh, curl, another check): a guard test fails the build.

### Task 1: `memo.py` (key, store, header)

**Files:**
- Create: `tools/site-standards/memo.py`
- Create: `tools/site-standards/tests/test_memo.py`

**Interfaces:**
- Produces:
  - `MEMO_HEADER = "# memo: commit"`
  - `is_memoizable(script_path: str) -> bool`: true if one of the first 20 lines equals `MEMO_HEADER`.
  - `tool_identity(standards_mcp: str) -> str`: hex sha256 over the bytes of `run-*.sh` in `standards_mcp` plus the output of `docker images --no-trunc --format '{{.Repository}}:{{.Tag}} {{.ID}}'` lines whose repository starts with `standards-`. If docker cannot be run, that part is the literal `no-docker`.
  - `check_key(*, commit: str, script: str, lib: str, helpers: list[str], param: str, facts: dict[str, str], tool_id: str) -> str`: hex sha256; `script`, `lib`, `helpers` are file paths hashed by content; `facts` is hashed in sorted-name order, `None` treated as `""`.
  - `memo_path(shortcode: str, state_home: str | None = None) -> str`.
  - `class Memo`: `__init__(self, path: str)` (a missing, unreadable or malformed file is an empty memo), `lookup(self, key: str) -> dict | None` (dict has `outcome`, `detail`, `at_utc`), `record(self, key: str, commit: str, outcome: str, detail: str) -> None` (ignores any outcome but `pass`/`fail`), `save(self, current_commit: str) -> bool` (drops entries for other commits; writes a temp file in the same directory then `os.replace`; on `OSError` prints one stderr line and returns False).
  - `remembered_label(at_utc: str) -> str`: `at_utc` is `YYYY-MM-DD HH:MM:SS` UTC; returns local time as `YYYY-MM-DD HH:MM TZ`.

- [ ] **Step 1: Write the failing tests** in `tools/site-standards/tests/test_memo.py` (`unittest`, temp directories, `sys.path.insert(0, parent dir)`). Names and assertions:
  - `test_header_found_in_first_twenty_lines`, `test_header_absent_is_not_memoizable`, `test_header_after_line_twenty_is_ignored`.
  - `test_key_changes_with_commit`, `..._with_script_bytes`, `..._with_lib_bytes`, `..._with_a_helper_file`, `..._with_param`, `..._with_a_fact`, `..._with_tool_id`; `test_key_same_for_none_and_empty_fact`; `test_key_stable_across_fact_order`.
  - `test_record_then_lookup_roundtrip` (save, reload through a new `Memo`, same dict back).
  - `test_unknown_and_other_outcomes_are_not_recorded` (`record(..., "unknown", ...)`, then `lookup` is None).
  - `test_save_drops_other_commits`.
  - `test_malformed_file_is_empty_and_save_rewrites_it` (write `{"trunc` to the path first).
  - `test_unwritable_state_dir_returns_false` (path under a read-only temp dir; asserts `save()` is False and nothing raises).
  - `test_memo_path_honours_xdg_state_home` and `test_memo_path_defaults_under_home`.
  - `test_remembered_label_shape` (regex `^\d{4}-\d\d-\d\d \d\d:\d\d \S+$`).

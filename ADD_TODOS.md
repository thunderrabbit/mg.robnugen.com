# Habit and Task Tracker with Timers

A clean, minimal productivity app that helps you build habits, manage todos, and track duration-based activities with smart timers.

---

## Core Features

### 1. Task Management

* **Daily Habits**: Recurring tasks that reset each day (exercise, read, journal)
* **Multi-frequency Tasks**: Tasks with a target count per day (drink water 8x, take breaks 5x)
* **Duration Tasks**: Activities requiring a timer (meditate 10 min, workout 30 min)
* **One-time Todos**: Regular tasks with optional due dates
* **Weekly/Monthly Tasks**: Recurring on specific days or intervals

### 2. Smart Timer System

* **Countdown Mode**: Set a target duration and count down to completion
* **Overflow Tracking**: After countdown reaches zero, timer automatically switches to counting up
* **Total Duration Recording**: Captures the full time spent, not just the minimum goal
* **Auto-complete**: Task marks as done when timer finishes (user can continue timing if they want)

### 3. Daily Dashboard

* Today's tasks organized by type (habits, timed activities, todos)
* Quick-complete buttons for simple habits
* Visual progress indicators for multi-frequency tasks (e.g., 5/8 water glasses)
* One-tap timer start for duration tasks

### 4. Progress & Statistics

* **Streaks**: Track consecutive days of habit completion
* **History View**: Calendar view showing completed tasks per day
* **Charts**: Weekly/monthly completion rates and trends
* **Duration Stats**: Total time spent on timed activities

### 5. User Accounts

* Username/password login and signup
* Data syncs across devices
* User profile with preferences

---

## Design Approach

* **Minimal & Clean**: Lots of whitespace, distraction-free interface
* **Mobile-First**: Works beautifully on phones for quick check-ins
* **Light/Dark Mode**: Toggle between themes
* **Soft colors**: Muted tones that aren't overwhelming
